# Wien BeamNG.drive – 6 Bezirke

Eine Wien-Map für BeamNG.drive mit den Bezirken:

- 1010 – Innere Stadt
- 1030 – Landstraße
- 1050 – Margareten
- 1060 – Mariahilf
- 1070 – Neubau
- 1150 – Rudolfsheim-Fünfhaus

## Features

- Straßen und Gebäudegrundrisse aus amtlichen Wiener Geodaten
- Texturierte Gebäude mit vereinfachten Fassaden
- Automatisch schaltende, leuchtende Ampeln
- Bushaltestellen
- Parks, räumliche Mauern, Zäune und Stufen
- KI-Straßennetz und zehn Startpunkte
- Korrektur des früheren Ladefehlers „Lade Basis“

Datenquelle: Stadt Wien – data.wien.gv.at.
